FINTECH 533 · LSEG + GitHub Actions

LSEG data, refreshed by one click

A GitHub Action logs in to LSEG, queries daily bars, saves the Plotly chart below into this site and commits it. GitHub Pages then republishes the page. LSEG Workspace does not need to be open anywhere.

Candles are daily open, high, low and close; the line is the 20-session average of the close; the lower panel is volume. The request ends at the previous trading day, because LSEG's bar for the current day is not final.

The cycle

  1. ClickOn GitHub: Actions → LSEG plot → Run workflow, and choose an instrument code (RIC). The default is NVDA.O.
  2. Querylseg_plot.py opens an LSEG platform session with the repository's secrets (LSEG_APP_KEY, LSEG_USERNAME, LSEG_PASSWORD) and asks get_history for about six months of daily bars.
  3. SaveIt draws the chart with Plotly and writes docs/lseg-plot.html, a self-contained element this page shows in a frame.
  4. PublishThe workflow commits that file. GitHub Pages rebuilds the site, and this page shows the new chart a minute or two later.
Script: lseg_plot.py ↗ Action: lseg-plot.yml ↗
